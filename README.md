# GoalInvest Advisor 💰

### Your AI-Powered Personal Finance Assistant

GoalInvest Advisor is an educational personal finance application that helps users understand financial concepts, plan savings goals, and learn about investments using AI-powered assistance.

## ✨ Features

- **AI Finance Assistant:** Learn about mutual funds, SIPs, diversification, savings, and investments.
- **Goal Planner:** Calculate the monthly savings required to reach your financial goals.
- **AI-Powered Guidance:** Get educational information to support financial learning and planning.
- **RAG-Based Question Answering:** Retrieve relevant information from financial documents to help answer user questions.
- **User-Friendly Interface:** Navigate through the application using a simple web interface.

## 🛠️ Technologies Used

- **Frontend:** React.js, Vite, JavaScript, CSS
- **Backend:** Python, FastAPI
- **AI & RAG:** LangChain, Hugging Face Embeddings, ChromaDB
- **Language Model:** Ollama (Llama 3.2)
- **Version Control:** Git and GitHub

## 📂 Project Modules

- Home
- AI Assistant
- Goal Planner
- About

## 🚀 Project Objective

The objective of GoalInvest Advisor is to make financial education more accessible by combining AI-powered question answering with goal-based savings calculations and financial learning resources.

## 🔮 Future Scope

- Add more financial educational resources.
- Improve AI-generated responses.
- Enhance the goal-planning experience.
- Deploy the application online for easier access.

## ⚠️ Disclaimer

This project is intended for educational purposes only. It does not provide personalized financial advice. Users should consult a qualified financial professional before making investment decisions.
